# Personalized Workout Generator 💪

A full-stack web application that generates personalized workouts based on available equipment and exercise preferences. Users can create accounts, save workouts, and track their fitness progress over time.

This project was built to demonstrate real-world full-stack development skills, including API design, authentication, database modeling, and frontend state management.

---

## Why this project?

I built this app to practice designing and shipping a complete product end-to-end — not just isolated features. It focuses on:

- Turning user input into structured, meaningful output
- Managing authenticated user state
- Persisting and querying data
- Connecting frontend UX with backend logic cleanly

Modern AI-assisted development tools (Cursor) were used to accelerate iteration, while maintaining full understanding and ownership of the architecture, logic, and codebase.

---

## Features

- **Personalized workout generation**
  - Based on available equipment, exercise type, and reps
- **User authentication**
  - Register, login, logout
- **Saved workouts**
  - Logged-in users can store generated workouts
- **Progress tracking**
  - Log sets/reps per exercise
  - View workout and progress history
- **Embedded exercise demos**
  - YouTube video embeds for guided form
- **Clean, responsive UI**
  - SPA-style navigation with modals and dynamic views
